# Quick Compatibility Reference

## Is WiCAN Compatible with My Setup?

Use this quick reference to determine if WiCAN will work with your vehicle and applications.

---

## Vehicle Compatibility

### ✅ Compatible Vehicles

WiCAN works with:
- **All OBD-II vehicles** (typically 2006+ in most regions)
- **CAN-based protocols**: ISO 15765-4
- **11-bit and 29-bit** CAN identifiers
- **Both 250kbit/s and 500kbit/s** CAN speeds

### ⚠️ Enhanced Compatibility

**WiCAN PRO** is recommended for:
- BMW vehicles (all models)
- MINI vehicles
- Vehicles with advanced OBD chips
- Maximum compatibility

### 📋 Verified Vehicles

See the [Supported Vehicles List](../config/automate/supported_vehicles) for a comprehensive list of tested vehicles with user-verified profiles.

## Connection Methods

### WiFi Connection

**Access Point Mode** (Default)
- SSID: `WiCAN_XXXXXXXXXXXX`
- Default IP: `192.168.80.1`
- Port: `3333`
- No password required

**Station Mode**
- Connect WiCAN to your WiFi network
- Use assigned IP address
- Or use mDNS: `wican_xxxxxxxxxxxx.local`
- Port: `3333`

### Bluetooth (BLE) Connection

- **Device Name**: WiCAN_XXXXXXXXXXXX
- **Supported Platforms**: iOS, Android
- **Note**: Windows 10 RealDash does not support BLE
- **Recommendation**: Disable BLE when not in use for better performance

### USB Connection (WiCAN-USB only)

- **Baud Rate**: 4000000 (USB serial communication - not CAN bus speed)
- **Protocol**: SLCAN or RealDash
- **Compatible**: SavvyCAN, RealDash, BUSmaster
- **Note**: This high baud rate is specific to WiCAN-USB and is documented in the official setup guides

## Protocol Selection Guide

Choose the right protocol for your application:

### ELM327
**Best For**: Generic OBD-II apps (Car Scanner, Torque, etc.)
- ✅ Widest app compatibility
- ✅ Works over WiFi and BLE
- ✅ Standard OBD-II commands
- ⚠️ Not auto-detecting (manual protocol selection required)

### RealDash 66
**Best For**: RealDash application
- ✅ High-performance CAN frame streaming
- ✅ Custom dashboards
- ✅ Works over WiFi, BLE, and USB

### SLCAN
**Best For**: SavvyCAN, BUSmaster, reverse engineering
- ✅ Raw CAN frame access
- ✅ High data rate
- ✅ Works over WiFi and USB

### GVRET
**Best For**: Vehicle reverse engineering tools
- ✅ Advanced CAN features
- ✅ Multiple bus support
- ✅ Timestamp support

## Configuration Quick Start

### For Generic OBD-II Apps (ELM327)

1. **Connect to WiCAN WiFi** (or configure to join your network)
2. **Open configuration page**: `http://192.168.80.1`
3. **Configure**:
   - CAN Speed: `500kbit/s` (most common) or `250kbit/s`
   - Protocol: `ELM327`
   - Enable BLE: If using mobile app
4. **In your app**:
   - Select WiFi or Bluetooth connection
   - IP: `192.168.80.1` (or your network IP)
   - Port: `3333`
   - Manually select protocol in app (e.g., "ISO 15765-4 CAN, 11 bit ID, 500 Kbaud")

### For RealDash

1. **Connect to WiCAN WiFi**
2. **Open configuration page**: `http://192.168.80.1`
3. **Configure**:
   - CAN Speed: Match your vehicle (usually `500kbit/s`)
   - Protocol: `RealDash 66`
   - Enable BLE: If using mobile
4. **In RealDash**:
   - Add Connection → Adapter (CAN/LIN)
   - Select RealDash CAN
   - Choose WiFi/BLE/USB
   - Enter IP and port (if WiFi)

### For SavvyCAN/BUSmaster

1. **Connect to WiCAN WiFi or USB**
2. **Open configuration page**: `http://192.168.80.1`
3. **Configure**:
   - CAN Speed: Match your vehicle
   - Protocol: `SLCAN`
4. **In SavvyCAN/BUSmaster**:
   - Select network connection or USB serial
   - Configure SocketCAN settings

## Troubleshooting Compatibility

### App Cannot Connect

**Check**:
- ✅ WiCAN is powered on (LED indicators)
- ✅ Connected to correct WiFi network
- ✅ Using correct IP address and port (3333)
- ✅ Protocol is set to correct mode (ELM327 for most apps)
- ✅ BLE is enabled if using Bluetooth

### No Data from Vehicle

**Check**:
- ✅ CAN speed matches vehicle (try 500k, then 250k)
- ✅ Vehicle is turned on (ignition in "ON" or "ACC" position)
- ✅ Manual protocol selection in app (e.g., ISO 15765-4 CAN)
- ✅ Vehicle actually supports OBD-II (2006+ in most regions)

### Performance Issues

**Optimize**:
- ✅ Disable BLE when not in use
- ✅ Disable MQTT when not needed
- ✅ Use WiFi instead of BLE for better performance
- ✅ Ensure stable power from vehicle

### Specific Vehicle Issues

**Solutions**:
- 🔍 Search GitHub issues for your vehicle make/model
- 💬 Join [Discord community](https://discord.com/invite/2hpHVDmyfw) for help
- 📱 Try WiCAN PRO for enhanced compatibility (especially BMW, Mini)

## Firmware Portability

### Can I Flash WiCAN Firmware on Other Devices?

**Short Answer**: No, not without significant modification.

**Why**:
- Hardware-specific design (ESP32-C3, specific CAN transceiver)
- Custom pin configurations
- Power management circuits
- Safety-critical automotive application

**If You Want to Port It**:
1. ⚠️ You need compatible ESP32-C3 hardware
2. ⚠️ You need hardware schematics
3. ⚠️ You must modify GPIO and hardware config
4. ⚠️ Extensive testing required for safety
5. ⚠️ Risk of bricking hardware or vehicle damage

**Recommendation**: Use official WiCAN hardware for safety and reliability.
