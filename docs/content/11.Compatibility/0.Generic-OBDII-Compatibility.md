# WiCAN Compatibility with Generic OBD-II Readers

## Understanding WiCAN

**WiCAN IS a wireless and Bluetooth-enabled OBD-II reader/adapter** - it is not software that runs on other OBD-II readers. This repository contains the firmware that powers WiCAN hardware devices.

### Key Facts:

1. **WiCAN is the Hardware**: WiCAN is a purpose-built OBD-II adapter with built-in WiFi and Bluetooth (BLE) capabilities.

2. **This Repository Contains the Firmware**: The `wican-fw` repository provides the firmware that runs on WiCAN hardware devices (WiCAN-OBD, WiCAN-USB, and WiCAN PRO).

3. **WiCAN Works AS a Generic OBD-II Reader**: WiCAN can function as a generic wireless OBD-II adapter that works with many third-party applications.

---

## Can WiCAN Replace a Generic OBD-II Reader?

**Yes!** WiCAN is designed to work as a wireless OBD-II adapter with many diagnostic applications. Here's what makes it compatible:

### Protocol Support

WiCAN supports multiple protocols that make it compatible with generic OBD-II tools:

1. **ELM327 Protocol**: Industry-standard protocol supported by most OBD-II applications
   - Compatible with Car Scanner, Torque, and many other apps
   - Works over WiFi and Bluetooth (BLE)

2. **RealDash Protocol**: Native support for RealDash custom dashboards
   - High-performance CAN frame streaming
   - Works over WiFi, BLE, and USB (WiCAN-USB only)

3. **SLCAN Protocol**: Serial Line CAN protocol
   - Compatible with SavvyCAN, BUSmaster
   - Works over WiFi and USB

4. **GVRET Protocol**: Generalized Vehicle Reverse Engineering Tool protocol
   - Additional compatibility with reverse engineering tools

### Connectivity Options

WiCAN provides multiple ways to connect:

- **WiFi (TCP/UDP)**: Connect over your local network or WiCAN's access point
- **Bluetooth Low Energy (BLE)**: Direct wireless connection from mobile devices
- **USB Serial** (WiCAN-USB only): Traditional wired connection

## Using WiCAN with Generic OBD-II Applications

### Compatible Applications

WiCAN works with many generic OBD-II applications:

#### Mobile Apps
- **Car Scanner** (iOS/Android): Full support via WiFi or BLE
- **Torque Pro** (Android): Works with ELM327 protocol
- **OBD Fusion** (iOS): Compatible via WiFi or BLE
- **RealDash** (iOS/Android/Windows): Native protocol support

#### Desktop Tools
- **SavvyCAN**: CAN bus reverse engineering
- **BUSmaster**: Vehicle network analysis
- **python-can/SocketCAN**: Programming and automation

#### Home Automation
- **Home Assistant**: MQTT integration for vehicle monitoring
- **Custom Applications**: APIs available for Python, C#, VB.Net, Delphi, LabView

### Configuration for Generic Use

To use WiCAN as a generic OBD-II reader:

1. **Connect WiCAN to your vehicle's OBD-II port**

2. **Configure via Web Interface** (default IP: `192.168.80.1`):
   - Set CAN baudrate (typically 500kbit/s or 250kbit/s)
   - Set Protocol to "ELM327" for maximum compatibility
   - Enable BLE if using mobile apps
   - Configure WiFi for network connectivity

3. **Connect from your application**:
   - **For WiFi**: Use WiCAN's IP address and port 3333
   - **For BLE**: Search for "WiCAN" device in your app's Bluetooth settings

## Can This Firmware Run on Other OBD-II Readers?

**Generally No** - The WiCAN firmware is specifically designed for WiCAN hardware. Here's why:

### Hardware Dependencies

WiCAN firmware is built for specific hardware:

1. **ESP32-C3 Microcontroller**: The firmware uses ESP32-C3 specific features
2. **CAN Transceiver**: Requires specific CAN interface hardware
3. **OBD-II Connector**: Hardware-specific pin configurations
4. **Power Management**: Custom voltage monitoring and sleep mode circuits

### Supported WiCAN Hardware Versions

The firmware supports these WiCAN devices:
- **WiCAN v2.1.0** (OBD form factor)
- **WiCAN v3.0.0** (OBD form factor)
- **WiCAN-USB v1.0.0** (USB form factor)
- **WiCAN PRO** (OBD form factor with advanced OBD chip)

### Could It Be Ported?

While theoretically possible to port the firmware to other ESP32-based OBD-II readers, it would require:

- **Hardware compatibility**: The target device must use similar components (ESP32-C3, compatible CAN transceiver)
- **Schematic knowledge**: Understanding of the target hardware's pinout and design
- **Firmware modifications**: Adapting GPIO pins, power management, and hardware-specific code
- **Testing and validation**: Extensive testing to ensure safety and reliability

**Important**: Attempting to flash WiCAN firmware on incompatible hardware could brick the device or cause safety issues. Only flash this firmware on official WiCAN hardware.

## Frequently Asked Questions

### Q: Can I use WiCAN with my existing OBD-II diagnostic app?

**A: Yes!** If your app supports ELM327 protocol over WiFi or BLE, it will work with WiCAN. Just configure WiCAN to use ELM327 protocol mode.

### Q: Do I need special hardware to use this firmware?

**A: Yes.** This firmware is designed specifically for WiCAN hardware devices. It won't work on arbitrary OBD-II readers without significant modification.

### Q: Can WiCAN read the same data as other OBD-II readers?

**A: Yes.** WiCAN has full access to standard OBD-II PIDs (Parameter IDs) just like any other OBD-II reader. Additionally, WiCAN PRO has enhanced compatibility with more vehicles.

### Q: Is WiCAN compatible with all vehicles?

**A: Most vehicles.** WiCAN works with:
- All vehicles with OBD-II (2006+ in most regions)
- Standard CAN protocols (ISO 15765-4)
- Both 11-bit and 29-bit CAN identifiers
- See the [Supported Vehicles](../config/automate/supported_vehicles) page for tested vehicles

**Note**: WiCAN PRO is recommended for maximum compatibility, especially with BMW and some other manufacturers.

### Q: What if I have a generic Bluetooth OBD-II reader?

**A: WiCAN and generic readers serve similar purposes** but WiCAN offers:
- Open-source firmware for customization
- More protocols beyond ELM327
- Advanced features (MQTT, automation, profiles)
- Better long-term support and updates

You can use WiCAN as a replacement or upgrade from generic readers.
